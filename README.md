# Orbit Proxy

Приложения для Windows 11, Android и Android TV: HTTP/SOCKS5-прокси, доменные исключения и подписанные обновления.

## Скачать

- [Последняя версия и исходники](https://github.com/nikitazavyalovyar-stack/orbit-proxy-updates/releases/latest)
- [Windows EXE](https://github.com/nikitazavyalovyar-stack/orbit-proxy-updates/releases/latest/download/OrbitProxy.exe)
- [Android / Android TV APK](https://github.com/nikitazavyalovyar-stack/orbit-proxy-updates/releases/latest/download/Orbit-Android.apk)

Публичные файлы не содержат личных учётных данных прокси или ключей персональных групп. Они подходят для обновления уже настроенных приложений и ручной настройки новых установок. Персональные первоначальные сборки передаются владельцу отдельно.

## Обновления

Приложение проверяет RSA-подпись манифеста, размер и SHA-256 файла. Android дополнительно проверяет имя пакета, версию и сертификат APK; установку подтверждает пользователь. На Windows перед заменой EXE завершается соединение и сохраняется предыдущий файл для отката.

Общие профили зашифрованы AES-256-GCM. Ключ группы хранится только в персональной первоначальной сборке и защищённом локальном хранилище устройства. Онлайн-проверка выполняется при запуске приложения, по кнопке и примерно раз в пять минут во время работы.

При первом переходе на Windows 1.3 включаются три настройки: оставлять в трее, запускать при входе в Windows и автоподключение. Последующие изменения этих настроек сохраняются.

## Исходники и ограничения

В каждом выпуске приложен архив соответствующих исходников, лицензий и инструкций сборки. Android использует sing-box v1.14.2; его исходники и условия GPL-3.0-or-later включены в архив. Orbit не является официальным клиентом SagerNet.

Windows использует системный HTTP-прокси для совместимых приложений. Android использует локальный VPN-интерфейс; UDP вне исключений отклоняется, так как передача UDP сервером не подтверждена. Доступность конкретного сайта зависит также от прокси-провайдера и самого сайта.
